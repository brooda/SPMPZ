# SPMPZ repository instructions

## Working style

- This repository is a non-production prototype.
- For reversible visual, content and code changes, make reasonable assumptions and execute without optional confirmation questions or ceremonial approval gates.
- Ask only when an action is destructive, needs secrets or external-account changes, or when a missing decision would materially change the requested outcome.

## Pull request scope

- For one requested implementation issue, use one comprehensive pull request.
- Split work only when Piotr explicitly asks or a hard technical/platform constraint makes one pull request impossible.
